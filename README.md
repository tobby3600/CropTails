# CropTails
CropTails is a 2D platform farming game, which is a demo of the [tutorial]([How to Build a Complete 2D Farming Game an 8-Hour Tutorial Series - Godot 4.3 - All 25 Episodes - YouTube](https://www.youtube.com/watch?v=it0lsREGdmc&list=PLWTXKdBN8RZe3ytf6qdR4g1JRy0j-93v9)).

## Extra Contexts

I add the following contexts to the original version:

- Load&Save system improved:
  - Support save player,inventory,time and more
- Settings UI
- Better moving detect
  - use stack to allow infinite input on wasd(only process the last key inputted)
- Illumination system
  - solar and lunar illumination
  - a portable torch on the player
